# Review Arsitektur dan Kualitas Kode — 28 November 2026

Review read-only terhadap kode IMM Observer. Fokus: struktur, konsistensi pola, cakupan tes, dan status temuan lama di `HANDOVER.md`. Tidak ada kode aplikasi, migrasi, atau konfigurasi yang diubah.

## Ringkasan 5 temuan teratas

1. **A01 (High) — Error Server Action masih tidak seragam.** Ada 273 `throw` di `app/`, `lib/`, dan `components/`. Wrapper inline hanya dipakai di Penilaian (`app/dashboard/penilaian/form-error.ts:28`) dan jalur finalisasi Evaluasi. Lima aksi Evaluasi lain masih melempar `Error` mentah (`app/dashboard/evaluasi/actions.ts:105,300,375,408,536`), begitu juga aksi Pengajuan, Kegiatan, Seleksi, Laporan, Pengguna, Impor Tes, dan Komisariat. Validasi yang diharapkan meruntuhkan halaman ke `error.tsx`.

2. **A02 (High) — Empat unit UI inti terlalu besar dan mencampur tanggung jawab.** `app/dashboard/penilaian/page.tsx:50` (1.684 baris), `components/phase7-report-workspace.tsx:115` (1.534 baris), `app/dashboard/evaluasi/page.tsx:48` (1.248 baris), dan `app/dashboard/observasi/page.tsx:26` (808 baris) memuat query Supabase, cek role, validasi, derivasi nilai, form, dan markup sekaligus. Logika ini praktis tidak bisa diuji unit dan sulit dibaca ulang.

3. **A03 (Medium) — Aturan agregasi indikator punya beberapa implementasi.** Rumus bobot/rata-rata hidup di `lib/scoring.ts:43`, `lib/phase6-scoring.ts:169`, `lib/auto-competency.ts:124`, dan `components/phase7-report-workspace.tsx:80,692`. Filter cakupan `cross_session` juga diulang di `app/dashboard/evaluasi/actions.ts:81`, `app/dashboard/evaluasi/page.tsx:307`, dan `lib/training-recap.ts:36`. Risiko angka berbeda antarhalaman bila satu titik diubah.

4. **A04 (Medium) — Validasi rubrik duplikat: UI vs server.** Halaman menghitung sendiri total bobot 100% dan panjang uraian skor 1–5 di `app/dashboard/penilaian/page.tsx:1098-1128`; Server Action mengulang aturan yang sama di `app/dashboard/penilaian/rubric-actions.ts:1505-1538`. Helper `lib/rubric-weights.ts` tidak dipakai untuk validasi ini.

5. **A05 (Medium) — Server Action kritis belum punya tes unit.** Dari 49 tes Node, tidak ada yang mengimpor berkas `*actions.ts`. Finalisasi, publikasi rapor, arsip kegiatan/peserta, dan penolakan akses hanya diuji lewat `supabase/tests/*.sql` (12 berkas) yang tidak termasuk `npm run check`.

## Status temuan lama yang diminta

- **254 `throw` validasi yang meruntuhkan halaman** (`HANDOVER.md:549,562-567`): masih ada, dan jumlahnya sekarang 273 `throw`. Yang sudah selesai: 17 aksi rubrik + 4 aksi penugasan dibungkus `runPenilaianAction`, serta jalur `finalize*` Evaluasi memakai `{ok:false}` + `?error=`. Yang belum: lima aksi Evaluasi lainnya (moderasi, simpan evaluasi, sunting rekomendasi, buat rekomendasi otomatis, setujui rekomendasi) dan seluruh modul aksi di luar Penilaian/Evaluasi. Lihat A01.
- **Duplikasi perhitungan indikator** (`HANDOVER.md:549,556`): masih ada sebagian. Yang sudah disatukan: pembuatan `PlannedIndicator` untuk aksi finalisasi dan halaman lewat `lib/evaluation-planning.ts` (`HANDOVER.md:556`). Yang belum: rumus skor lintas modul, filter `cross_session`, dan validasi rubrik UI vs server. Lihat A03 dan A04.
- **Alias modifier CSS lama** (`HANDOVER.md:753,758`): masih ada dan sengaja dipertahankan karena nilai status dinamis. Bukan bug, hanya utang refactor. Lihat A09.
- **Judul "Versi 2 · RESMI" dengan badge "Draf"** (`HANDOVER.md:745`): masih ada di `app/dashboard/penilaian/page.tsx:1133-1150`. Lihat A08.
- **Cast `as unknown as`** (`HANDOVER.md:549,567,601`): sudah selesai, kecuali satu batas yang memang disengaja di `lib/relations.ts:43`. Lihat A11. Cast tanpa validasi lain masih ada dan dibahas di A06.
- **Warning hooks (`set-state-in-effect`, `exhaustive-deps`) dan trik `setTimeout(0)`** (`HANDOVER.md:44,104,603-604`): sudah selesai. `npm run lint` saat review: 0 error, satu warning `WHITE` (A10).
- **Tambahan, sudah selesai di kode:** RPC `get_event_assessment_summary` kini menerima `target_participant_id` (`app/dashboard/evaluasi/actions.ts:425-427,649`), sehingga temuan pemotongan 3.069 baris di `HANDOVER.md:441-449` sudah tidak berlaku pada jalur yang memakai parameter itu.
